# ADR-0003 解读层 LLM 方案

## 状态：已接受

## 上下文

需求：解读是报告核心（队伍/人员画像、联赛规律、情报含义等段纯解读），且"不可省略"（6.9）；又要求"不引入新事实"（6.9-1）+ 赛中快报 ≤2 分钟时效 + 成本"每份数分钱、每晚数元"（NFR-C-1）。

## 决策

- **供应商**：DeepSeek 官方 API（OpenAI 兼容）。中文强、便宜、延迟可控。
- **结构化约束**：提示词版本化（`prompts/`），输出受 JSON Schema（段 id → 文本）。
- **反幻觉后置校验**（不靠提示词自觉）：
  1. 抽取解读文本中的数字 / 选手名 / 比分；
  2. 逐个检查是否出现在事实层输入中；
  3. 出现新事实 → 丢弃重试 1 次 → 再失败降级规则直出并标记 `llm_state='rule_fallback'`。
- **成本硬闸**：**单场 ≤ ¥0.3、每日 ≤ ¥10**。触及任一 → 立即转规则直出 + 报警。
- **降级策略（D9）**：**规则直出兜底**——报告按时发布，质量降级并标注"解读能力降级"，不静默降级。
- **长时间不可用**：连续 3 次调用失败 → 全局降级并在站点显示状态。

## 后果

- ✅ 成本可测算、可闸控。
- ✅ 赛后完整版同样走此路径（避免"赛中用 LLM、赛后换规则"的漂移）。
- ⚠ 事实层产物必须自洽——如果事实层输入有误，解读层跟着错（后置校验只能查"新事实"，不能查"错误事实"）。
- ⚠ 规则直出兜底的质量基线取决于蓝本 `render_fast_intel.py` 模板的成熟度。
