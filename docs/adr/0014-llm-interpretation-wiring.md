# ADR-0014 解读层 LLM 落地：凭据、受约束输出、反幻觉边界、成本闸与降级

## 状态：已接受

## 上下文

需求 FR-C4-3/10/11、§6.9 第 1–4 条、§6.10、NFR-C-1/2/3、NFR-Q-5、NFR-S-4、AC-12/AC-16；
设计 §10.2/§10.3/§10.4、§14.4；ADR-0003。T5（#8）已经把解读层做成注入缝
（`Interpreter` 协议：`state` + `interpret(spec, facts)`），缺口只剩"接真 LLM"。
接口级必须在实现时定死、设计文档没写到的东西有几处：

- 凭据放哪个 `.env`、权限怎么查、密钥怎么保证不进库/不进页面/不进日志；
- 一次调用解读一段还是解读全部段；输出契约（JSON Schema）长什么样；
- `prompts/` 的目录结构与"版本"的含义，改段集时怎么强制改提示词；
- 反幻觉校验的**允许集**边界——哪些数字/名称不算"新事实"（否则每一句都误伤），
  哪些拦不住（不能假装能拦）；
- 校验失败与调用失败分别怎么处理（重试几次、超时算不算失败）；
- 单场 ¥0.3 / 当日 ¥10 的判定时点与记账表；
- `reports.llm_state` 只有 `llm` / `rule_fallback` 两个值，那"为什么降级"写哪；
- "连续 3 次调用失败 → 全局降级"（ADR-0003）的状态存在哪、怎么恢复。

## 决策

1. **凭据只从数据目录下的 `.env`（0600）读**：`<数据目录>/.env`（默认
   `~/danmu-intel-data/.env`，与 db/raw 同级，测试用 `DANMU_INTEL_DATA` 隔离）。
   键：`DEEPSEEK_API_KEY`（必需），`DEEPSEEK_MODEL` / `DEEPSEEK_BASE_URL`（可选覆盖）。
   权限位不是 0600 时**拒绝读取**（宁可不发，不可泄露）；密钥不进库、不进站点产物、
   不进日志与错误消息；测试断言页面、库、仓库与 `git log -p` 里零命中。
2. **一次调用解读一段**（T5 定下的缝不动：`interpret(spec, facts)` 一次一段）。
   输出契约固定为 `{"segments": {"<段号>": "<文本>"}}`，用 `response_format=json_object`
   约束；**键集必须与本次请求的段集完全一致**（少键、多键、空文本都算不合格）。
   单次调用超时 25 秒（设计 §10.2 的 `interpretation` 阶段预算）。
3. **提示词按版本放目录**：`prompts/interpretation/<版本>/{system.md,user.md,segments.md}`。
   代码里的 `PROMPT_VERSION` 是唯一版本来源；`segments.md` 必须为**每个**解读段
   （2/3/4/6/7/8/9）提供小节，缺一段直接报错——段集变了就必须改提示词，不允许静默沿用。
   `user.md` 用 `string.Template` 的 `$name` 占位（提示词里会出现 JSON 花括号，不能用 `format`）。
   每次调用把 `prompt_version` 记进账本，报告由此可回溯"这句话是哪版提示词生成的"。
4. **反幻觉的允许集 = 模型看到的那份输入本身**：事实层规范 JSON（`fact_layer_payload`）
   里出现过的数字、拉丁词，加上该 JSON 里时间戳的格式化写法（`format_ts` 的日期与时刻分量，
   是同一批毫秒值的确定性改写——事实层里只要出现一个毫秒值，这个值的日期/时刻写法就算数）。
   抽取前先屏蔽**结构编号**（`第 N 段`、`G<局号>`），它们不是事实断言。比分（`N:N`）与
   百分比（`N%`）按**整体**比对，不拆成数字（否则事实层里任意出现过的 `3` 和 `0`
   会让编造的 `3:0` 蒙混过关）。名称的判定方式是「这个拉丁词是否出现在输入 JSON 里」
   （大小写不敏感）：因此 `iG`/`LPL`/哈希片段放行，`Faker`/`T1` 拦下；角色与技术缩写
   （MVP/KDA/BP/ADC…）另有一张与任何具体人无关的白名单。任何 `user_hash` 出现在解读文本里
   即作废（需求 §6.5 第 2 条在解读层的延续）。
   **已知局限（不假装能拦）**：中文昵称/中文队名在无 NER 的情况下无法识别；事实层里
   没有花名册，因此中文人名本就不该出现——这条靠提示词纪律 + 人工抽检兜底。
5. **两类失败分别处理**：
   - 幻觉/契约不合格（校验未过、JSON 解析失败、键集不符）→ 丢弃该段**重试 1 次**
     （第二次把违规项清单回灌给模型）→ 仍失败则该段规则直出；
   - 超时/网络/API 报错 → **不重试**（省的是快报的预算，ADR-0003 的降级路径本来就存在）
     → 该段直接规则直出。
   任一降级都把 `llm_state` 记为 `rule_fallback`（那一段是规则文本，整份报告如实标降级）。
6. **记账表 `llm_calls`**：每次调用一行（含被闸掉的 `gated`），记
   `match_id / segment_no / model / prompt_version / prompt_tokens / completion_tokens /
   cache_hit_tokens / cost_cny / latency_ms / outcome / reason / created_at`。
   价格表在 `report/llm/cost.py`（元/百万 tokens），取 DeepSeek 官方定价的**高峰价**
   （保守高估成本：宁可早闸，不可事后才发现超了）；`estimate_cost_cny` 是纯函数，
   未登记价格的模型拒绝记账并当场降级（宁可不发，不可算错）。
7. **硬闸在调用之前**：`SUM(llm_calls.cost_cny)` 单场 > ¥0.3 或当日（采集机本地日历日，
   ADR-0001 单机部署）> ¥10 → 本次不再调用、当次降级、写一行 `llm_cost_gate` 报警
   （`notifications(state='pending')`，投递属 T11）；同一份报告里这类报警**只写一行**。
8. **全局降级从账本推导，不另存状态**（与"统计可重算"同一思路）：最近调用里连续
   ≥3 次失败（`timeout` / `error` / `rejected`）即视为长期不可用，后续段落不再调用 LLM，
   直到出现一次成功调用自动恢复。被闸住的 `gated` 行在健康判定里**透明**：既不算失败
   （算了就会自锁：一降级就再也恢复不了），也不重置连续失败（否则"降级 → 记一行 gated
   → 下次又试"会变成循环）。`reports.llm_state` **仍只有 `llm` / `rule_fallback`
   两个值**（不新增值，避免库内语义漂移）；降级的**原因**写进 `ReportHeader.llm_note`，
   由第 10 段正文与页面横幅显式标注（不静默降级）。
9. **解读阶段总预算 = `forms.STAGE_BUDGET_MS["interpretation"]`（25 秒）**：剩余预算不足
   即不再调用（该段规则直出），单次超时取 `min(25s, 剩余预算)`。快报 2 分钟内一定发布，
   代价是慢的时候后面的段降级——降级可见，超时不可见，选前者。

## 后果

- ✅ 成本可测算可闸、降级有原因可查、密钥零入库（AC-12 的代码侧防线）。
- ✅ 反幻觉的后置校验是硬拦（不是提示词自觉），且"允许集 = 输入本身"这一点可测。
- ✅ 提示词版本与段集强绑定：加/删解读段时不会悄悄用旧提示词。
- ⚠ 一段一调用意味着调用次数 = 解读段数（快报 7 段），成本随段数线性；前缀缓存
  （system + 事实层 JSON 固定）能压住一部分输入价，但账本按实际 usage 记。
- ⚠ 价格表是代码常量：DeepSeek 调价必须改代码，且历史行按当时的代码价记账，
  因此**跨调价的历史成本不可换算**（只保证闸门与当日/单场口径一致）。表里取的是
  官方**高峰价**，属于故意的高估（宁可早闸）。
- ⚠ 规则直出兜底文本必须自己也过一遍反幻觉校验（已加测试）：事实层里没有的数字
  （拿本仓库举例：早前规则文本里的"设计 §19 M6""NFR-L-4"这类引用）会被判成新事实，
  所以那些引用被改写成了不带数字的说法。解读层不许引数字就得所有产出路径都守。
- ⚠ 中文昵称拦截缺位；"指控性结论"（§6.9 第 3 条）也没有可靠的自动判定，
  只能靠提示词纪律，不写一个看起来能拦、实际拦不住的检查。
- ⚠ **提示词注入**：事实层 JSON 里含弹幕原文（灰信号样本），恶意弹幕有可能夹带指令。
  后置校验能拦住它在产出里新造数字/名称与身份泄漏，但拦不住纯中文措辞层面的诱导；
  另一道防线是证据门槛（样本要过多人多时段才进事实层）与人工抽检。
- ⚠ `llm_calls` 只增不改，与 `metrics` 一样可对账；但它是**外部副作用**（真花了钱），
  不像统计那样可以随便重算——重跑报告会真花钱，因此 `rebuild` 永不碰 LLM 路径。
- ⚠ 本仓库没有可用的真实密钥，因此**真调用的 HTTP 路径只有单测（假传输层）覆盖**，
  没有联网实测过的"真账号联通"证据；换机器后先用一份 `full` 报告核对
  `llm_calls` 里的 tokens 与费用。
