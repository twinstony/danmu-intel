# ADR-0009 付费墙判定方式

## 状态：已接受

## 上下文

需求 6.7：付费墙判定依据是"比赛是否已结束"，**禁止按文件名/路径做一刀切**。蓝本曾因按文件名正则匹配 Pro 页面造成"已结束的比赛仍被锁"（2026-08-26 修复）。

## 决策

- **判定驱动**：只由比赛**状态机**（`matches.state`）驱动。
  - `state != ended` → 付费；
  - `state == ended` → 自动再发布为公开版。
- **永不依赖**：文件名 / 路径 / 正则 / 文件名里的日期。
- **"已结束"综合判定**（6.7）：任一成立即可——结算信息已回填 / 全部小局标记结束 / 比赛结果已回填。
- **赛后自动转公开**（FR-C5-10）：比赛结束后，该场**全部节点页**自动转公开，不存在"已结束但仍被锁"的比赛。

## 后果

- ✅ 修正蓝本按文件名判定的教训。
- ✅ 状态机是唯一真相源（single source of truth），避免多处逻辑不一致。
- ⚠ 状态机必须可靠——需终局判定逻辑（需求 6.4：≥3 类相互独立信号同时成立 + 2 分钟无反转）兜底。
