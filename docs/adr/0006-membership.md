# ADR-0006 会员开通方式

## 状态：已接受

## 上下文

需求 AC-3：订阅到访问权全程无需人工干预；需求 Q-5：不要求注册本站账号；需求 Q-6：收款仅 Polygon + Solana。

## 决策

- **全自助页面流程**（选档 → 填既有通讯账号 → 显示专属收款地址+金额 → 链上确认 → 自动开通 → 用户凭通讯账号领取凭据）。
- **防枚举**：校验接口 `POST /api/verify` 对「不存在」「未开通」「已过期」返回**完全相同的响应体**，仅凭随机凭据区分成功路径（AC-10）。
- **限流**：按 IP 和按账号双维度（NFR-S-2）。
- **凭据**：32 字节随机码，**只存哈希**；下发 HttpOnly + Secure + SameSite=Lax 的 cookie。
- **续费**：从原到期日顺延（AC-6），不是从付款日。

## 后果

- ✅ 用户无需"注册"——凭既有通讯账号（TG @name / QQ 号）直接领取。
- ✅ 响应不可区分 → 枚举攻击不可行。
- ⚠ 验证响应"不可区分"的语义与"快速错误反馈"之间存在张力——**安全优先**。
- ⚠ 凭据重发需走通讯账号验证 + 限流，不能自助重发无限制（防骚扰）。
